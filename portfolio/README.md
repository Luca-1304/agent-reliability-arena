# Implementation portfolio

This folder translates the repository's technical reliability work into public-safe implementation cases for employer and client review.

## AI Operations Assurance

A synthetic protection-insurance operations case demonstrating:

- workflow and stakeholder discovery;
- source-linked evidence and conflict handling;
- human approval and authority separation;
- independent completion verification;
- migration, shadow mode, pilot and rollback planning;
- functional and adversarial testing;
- operational metrics and an explicitly illustrative value model;
- honest evidence and publication boundaries.

### Run the evidence-contract demo

From an editable install at the repository root:

```bash
python -m pip install --editable .
python -m agent_reliability_arena.portfolio_demo
```

Use `--json` for the full canonical event and evaluation report:

```bash
python -m agent_reliability_arena.portfolio_demo --json
```

The committed suite covers verified completion, false success without observation, stale approval, duplicate retry, rollback and completion proved despite no agent claim. The branch's Python test matrix and CodeQL workflow verify the executable path.

## Evidence boundary

These are synthetic implementation simulations. They do not claim production deployment, real customer data, regulated advice, measured customer outcomes or unaided software authorship. Inspect the repository root's `EMPLOYER_REVIEW.md`, contribution record, project status and publication boundary for the underlying technical evidence and limitations.
